# 多目录工作区

[English](guide.md) | 中文

## 变更

工作区包含一个主要目录和可选的附加目录。新会话从主要目录开始，并固定保存附加目录。编辑工作区只影响新会话；已有会话保留原工作目录与访问配置。移除目录关联不会删除文件，也不会撤销已有会话的访问权限。

工作区存储从领域版本 2 升为 3。版本 2 记录读取时具有空的附加目录列表，首次成功写入会原子发布版本 3。工作区身份、名称、会话归属、排序、置顶和归档均保留。旧应用拒绝新的工作区版本。包含附加目录的会话带有必需识别的 `sandbox/directories` 事件；不认识该事件的读取方会拒绝这些会话。

## 迁移

1. 升级前停止应用，备份完整 Harness 主目录。备份与活动目录分开保存，并包含单独配置的外部存储位置。
2. 安装新应用并正常启动，无需移动目录或手工编辑记录。编辑工作区前，核对原有工作区、会话顺序、置顶和归档。
3. 打开**编辑工作区**添加目录。移除当前主要目录前，先对其他目录选择**设为主要**。必须至少保留一个目录。一次保存提交整个表单；取消不改变已保存配置。
4. 创建新会话，核对其工作目录与文件面板。写入仍受当前沙箱模式控制；添加目录不会开启无限制访问。
5. 如需恢复旧应用，先停止新应用，将完整的升级前备份恢复到独立主目录，再用旧版本打开。此恢复不包含新格式会话和备份之后的变更。不要调低存储版本号或删除会话事件。
